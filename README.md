# Nossa rotina semanal

Quadro interativo para Mateus, Débora e Nikova. HTML, CSS e JavaScript sem compilação.

- Marcação individual de 35 tarefas por semana.
- Progresso total e por pessoa, filtros e navegação semanal.
- Revezamento automático, com base na semana de 19/10/2026.
- Histórico salvo em localStorage por semana e navegador, sem sincronização entre aparelhos.
- Layout responsivo, navegação por teclado e rótulos acessíveis.

## GitHub Pages

Em Settings → Pages, selecione Deploy from a branch, branch main, pasta / (root). Salve. Os arquivos index.html, style.css e app.js devem estar na raiz do repositório.

As marcações não são enviadas ao GitHub. Limpar os dados do navegador remove o histórico local.
